Instead of switching between multiple WhatsApp groups, social media pages, websites, and mobile apps, students can access everything they need from one platform.

## 🎯 Our Mission

To make campus life simpler, smarter, and more connected by providing a single digital platform where students, businesses, and service providers can interact seamlessly.

---

## 👁️ Our Vision

To become Africa's leading digital campus ecosystem, connecting students with opportunities, businesses, services, and each other.

---

## 💡 Why MoiHub Exists

Campus life is full of fragmented services.

Students often struggle to find:

- 🍔 Affordable meals
- 🛍️ Trusted online shops
- 🏠 Rental houses
- 👥 Roommates
- 🏪 Campus businesses
- 📚 Academic materials
- 📦 Delivery services
- 🔧 Trusted technicians
- 📅 Event information
- 💼 Student opportunities

Most of these services are scattered across WhatsApp groups, Facebook pages, Telegram channels, posters, and word of mouth.

**MoiHub brings them together in one platform.**

---

## 🎓 What Students Can Do

Students can use MoiHub to:

- 🍽️ Order food from nearby vendors
- 🛒 Shop from campus businesses
- 🔄 Buy and sell second-hand items
- 🏘️ Find rental houses
- 🤝 Connect with roommates
- 🔍 Discover campus services
- 📖 Read campus blogs and updates
- ✅ Access verified businesses
- 💬 Chat with vendors
- 🔔 Receive important notifications

Everything is designed around making daily campus life easier.

---

## 🏪 What Businesses Get

MoiHub helps businesses reach thousands of students without needing their own website or mobile application.

Businesses can:

- 🏷️ Create an online storefront
- 📦 Upload products
- 💬 Receive customer inquiries
- ✨ Showcase services
- 🏢 Build their brand
- 🔗 Share their public store link
- 📈 Reach new customers across campus

Whether it's a food vendor, fashion store, electronics shop, salon, pharmacy, or freelancer, MoiHub provides a digital presence.

---

## 🌐 Public Storefronts

Every business receives a shareable web storefront.

These storefronts allow vendors to promote their business anywhere online:

- 📱 WhatsApp Status
- 📸 Instagram Bio
- 🎵 TikTok Profile
- 📘 Facebook
- 🐦 X (Twitter)
- 📱 QR Codes
- 📄 Printed marketing materials

**Example:** `https://moihub-silk.vercel.app/food/tasty-taters`

Customers can browse products before opening the MoiHub app to complete their experience.

## ⚡ Platform Features

### 🍔 Food Marketplace
Students can discover nearby food vendors, browse menus, and order meals conveniently.

### 🛍️ E-Shop
An online marketplace where businesses sell products directly to students.

### 🔄 Marketplace
A second-hand marketplace for buying and selling items within the campus community.

### 🏘️ Rentals
Helping students discover available hostels, bedsitters, apartments, and rental listings around campus.

### 👥 Roommate Finder
Connecting students looking for compatible roommates.

### 🔧 Campus Services
A directory of trusted campus service providers including:
- Photocopy services
- Laundry
- Repairs
- Beauty services
- Printing
- Freelancers
- Technical services

### 📖 Campus Blog
A platform for sharing campus news, student stories, guides, and useful information.

### 🏷️ Vendor Profiles
Every verified business has a dedicated public profile featuring:
- Business information
- Products
- Contact details
- Store images
- Business branding

### 🤖 MoiHub AI
Smart search powered by AI to help students find services, products, and information using natural language.

## 🛠️ Installation

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Clone the repository
```bash
git clone https://github.com/kylexvin/moihub.git
cd moihub
```

### Install dependencies
```bash
npm install
# or
yarn install
```

### Start development server
```bash
npm start
# or
yarn start
```

### Build for production
```bash
npm run build
# or
yarn build
```

## 🔐 Environment Variables

Create a `.env` file in the root directory:

```env
# API
REACT_APP_API_URL=https://moihub.onrender.com/api

# Google OAuth
REACT_APP_GOOGLE_CLIENT_ID=your_google_client_id

# Firebase (if using)
REACT_APP_FIREBASE_API_KEY=your_firebase_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_firebase_project_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_firebase_messaging_sender_id
REACT_APP_FIREBASE_APP_ID=your_firebase_app_id
REACT_APP_FIREBASE_MEASUREMENT_ID=your_firebase_measurement_id
```
